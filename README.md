# IndianHouse-price-prediction-model

#  Indian House Price Prediction Model

A Machine Learning project focused on predicting house prices in Indian cities using Python and Google Colab. This project was built using a limited Kaggle dataset containing approximately 1,807 records and explores the fundamentals of predictive analytics and regression modeling.

---

#  Project Overview

This project analyzes apartment pricing trends across Indian cities and implements a Linear Regression model to predict average housing prices based on available pricing data.

The workflow includes:

* Data preprocessing
* Cleaning and handling missing values
* Feature engineering
* Correlation analysis
* Data visualization
* Model training & evaluation

---

#  Tech Stack

* Python
* Google Colab (IPython Environment)
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

---

#  Dataset

Dataset Source: Kaggle
Dataset Size: ~1,807 records

The dataset contains apartment pricing information from multiple Indian cities.

---

#  Machine Learning Workflow

1. Imported and cleaned housing dataset
2. Removed null and invalid values
3. Processed price range columns into numerical format
4. Performed correlation analysis & visualizations
5. Trained a Linear Regression model
6. Evaluated model performance using:

   * R² Score
   * Mean Absolute Error (MAE)
   * Root Mean Squared Error (RMSE)
